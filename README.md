## ✨ Key Architectural Highlights

### 1. 🪐 Interactive 3D Developer System Network (`Hero3DScene.jsx`)
- Built with **pure Three.js** using WebGL rendering.
- Real-time conceptual system network interconnecting:
  - `PYTHON` (`#1B2CC1`)
  - `REACT` (`#7692FF`)
  - `REST API` (`#78B3CE`)
  - `DATABASE` (`#84B179`)
  - `ML & AI` (`#A2CB8B`)
  - `GIT / CI` (`#F96E2A`)
- Real-time data particle stream travelling across connection nodes with cursor parallax.
- Automated fallback to responsive SVG/CSS when WebGL is unavailable or when `prefers-reduced-motion: reduce` is detected.

### 2. 👤 Professional Portrait Integration (`ProfilePortrait.jsx`)
- Clean rectangular 4:5 portrait slot at `/public/images/arjun-profile.jpg`.
- Features 18px rounded corners, fine borders, and floating metadata badge (`ARJUN M BABU • FULL-STACK`).
- Clean fallback placeholder (`Add profile photo`) when the image file is not yet deployed.

### 3. 🌗 3-Mode Theme Provider with Anti-Flash (`ThemeContext.jsx`)
- Supports **Light**, **Dark**, and **System Preference**.
- Synchronizes with `localStorage` and system media queries.
- Zero theme-flash on reload via inline pre-render bootstrap script in `index.html`.

### 4. 🗂️ Alternating Project Showcases & Case Studies (`Projects.jsx`)
- 01 Text Left / Visual Right → 02 Visual Left / Text Right alternating grid.
- Custom interactive application blueprints for:
  - **Career Recommendation System**: 72-D vector soft-voting ensemble (XGBoost, CatBoost, LightGBM, Random Forest) + SHAP.
  - **WEBSHIELD**: Security Operations telemetry dashboard (SQL injection / brute force classifier).
  - **ChRoMALaB**: 14-tool color theory engine with WCAG 2.1 AAA contrast and CVD filters.
  - **WeatherVista**: 3D Three.js Earth globe with Open-Meteo live atmospheric telemetry.
  - **Rock Identification Studio**: 13-class geological CNN computer vision model.
  - **Quiz Application**: Timed anti-tamper examination portal with MySQL backend.
- Interactive deep-dive modal featuring an animated data pipeline (`USER` → `FRONTEND` → `FLASK API` → `MYSQL` → `ML INFERENCE` → `RESULT`).

### 5. 🗺️ Continuous Learning Roadmap (`LearningJourney.jsx`)

## ⚡ Getting Started

### Prerequisites
- Node.js (v18.x or later)
- npm (v9.x or later)

### Installation
```bash
# Clone the repository
git clone https://github.com/AMB-007/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install
```

### Development Server
```bash
# Start Vite development server
npm run dev
```
Open [http://localhost:3001](http://localhost:3001) in your browser to view the application.

### Production Build
```bash
# Compile and optimize production bundle
npm run build

# Preview production build locally
npm run preview
```

## 🏆 Performance, SEO & Accessibility Standards

- ⚡ **Zero TypeScript Dependencies**: 100% pure JavaScript & JSX (`.js`, `.jsx`, `.css`).
- 🚀 **Fast Loading**: Tree-shaken bundle, lightweight Three.js geometry, zero heavy image dependencies.
- ♿ **WCAG 2.1 Compliant**: High contrast ratios in both light mode (`#091540` on `#FFFAF3`) and dark mode (`#FFFAF3` on `#091540`).
- 📱 **Fully Responsive**: Verified layouts across mobile (`320px–425px`), tablet (`768px–912px`), desktop (`1024px–1440px`), and ultra-wide screens (`1920px+`).
- 🦺 **Reduced Motion Friendly**: Automatically disables 3D parallax, cursor movement, and complex animations when `prefers-reduced-motion: reduce` is active.
